Bazel BEP Review

This page is the review surface for BEP uploads that already arrived through BES gRPC handoff or the HTTP ingest path. Rendering stays in the browser; the worker only stores the latest 50 uploaded reviews and serves them back to the UI.

Bazel Setup

gRPC BES

Point Bazel at the private gRPC ingress that sits behind Cloudflare Tunnel. The review UI reads the normalized uploads later from the worker. 


                


                

                  

                    

                      
Metrics Coverage

                      recommended
                    

                    

                      Keep action and test timing signals enabled so the browser can render cache,
                      compile, IO, and flaky-test breakdowns from stored uploads.
                    

                    

                  


                  

                    

                      
HTTP Handoff

                      grpc-ingest
                    

                    

                      Configure the thin gRPC ingress to post normalized invocation payloads to the
                      worker. Uploaded records are persisted in D1 and capped at the most recent 50.
